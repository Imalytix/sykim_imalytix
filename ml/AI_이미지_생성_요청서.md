# AI 생성 이미지 준비 요청

안녕하세요, Imalytix에서 "AI로 생성된 이미지인지 판별하는 모델"을 학습시키고 있습니다.
모델이 정확히 배우려면 **"진짜 AI가 만든 이미지" 샘플**이 필요한데, 그중 일부를
Midjourney(팀에서 이미 쓰고 있는 도구)로 직접 생성해서 채우려고 합니다.
아래 안내대로만 해주시면 됩니다. 어려운 작업 아닙니다.

## 무엇을, 몇 장

아래 4개 카테고리 각각 **최소 40장, 가능하면 80장 이상**을 Midjourney로 생성해주세요.
카테고리별로 아래 예시 같은 내용이면 됩니다 (프롬프트는 자유롭게 다양하게 — 같은 구도만
반복하지 말고 인물/각도/배경을 다양하게 섞어주세요):

| 카테고리 | 무엇 | 프롬프트 예시 키워드 |
|---|---|---|
| **person** | 인물 사진 (얼굴/전신, 실제 인증샷처럼 자연스러운 느낌) | portrait, person, selfie, face, 다양한 연령/성별 |
| **building** | 건물/실내 공간 | interior, architecture, apartment, room |
| **misc** | 생활용품/잡화 | household item, kitchen, desk, still life |
| **item** | 가방·시계·신발 등 리세일 상품류 | handbag, watch, sneaker, jewelry, necklace |

**주의사항**
- ⚠️ **실제 사람 얼굴을 참조 이미지로 넣지 마세요** (지인/유명인 얼굴 업로드 후 생성 금지) — 100% Midjourney가 새로 생성한 얼굴이어야 합니다.
- ⚠️ item 카테고리는 가능하면 **실제 브랜드 로고가 뚜렷하게 보이지 않는** 이미지로 부탁드립니다 (상표권 이슈 예방 차원 — 로고 없는 각도/디자인이면 충분합니다).
- 선정적/폭력적/불쾌감을 주는 이미지는 제외해주세요.
- 해상도는 Midjourney 기본 출력이면 충분합니다 (업스케일 안 해도 OK).

## 저장/전달 방법

1. 카테고리별로 폴더 4개 만들어서 (`person`, `building`, `misc`, `item`) 각각에 이미지 저장 (파일명은 자유— 스크립트가 폴더 안 전체를 읽습니다)
2. 완료되면 [전달 방법 — 공유 드라이브 링크 / Slack 채널 등 여기에 채워주세요]로 전달
3. 받으면 제가 `ml/data/<카테고리>/ai_generated/`에 넣고 나머지 파이프라인 진행하겠습니다
