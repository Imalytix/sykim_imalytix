## 방향 전환 — 익스텐션 개발 중단

`extensions/chrome/`은 앞으로 버그 수정 외 신규 기능 개발 안 함. 대신 익스텐션이 웹서비스를 호출하는 **API 경계를 명세서로 고정**해서(`docs/API_SPEC_EXTENSION.md`), 웹서비스 쪽 UI/기능이 계속 바뀌어도 익스텐션이 의존하는 계약은 안정적으로 유지되도록 정리했습니다.

## 상세 분석 로그인 필수 전환

전달주신 플로우 목업대로 구현했습니다 — **요약(점수/핵심결과/해석)까지는 비로그인도 그대로 보이고, "자세한 분석"(provider별 breakdown·EXIF/C2PA·유사 이미지 검색)만 로그인 후 열립니다.**

⚠️ 참고: 이건 7/25경 "로그인 없이 사용할 수 있게" 하셨던 결정을 뒤집는 겁니다 — 오늘 확인 여쭤봤고 "네, 로그인 필수로 바꿀 것"으로 확정 답변 주셔서 진행했습니다.

### 구현 방식

- `components/results/AnalysisResultView.tsx`가 마운트 시 `supabase.auth.getUser()`로 로그인 상태 확인
- 비로그인 상태에서 "자세한 분석 보기" 버튼 → "로그인 후 자세한 분석 보기"로 문구 변경, 클릭 시 즉시 Google 로그인 시작(별도 `/login` 페이지 경유 없음)
- 로그인 완료 후 **원래 보던 그 결과 화면으로 정확히 복귀**합니다 — 이게 까다로운 부분이었는데, `signInWithOAuth`의 `redirectTo`에 `?next=` 파라미터로 돌아올 경로를 실어보내는 방식으로 해결했습니다:
  - 홈(`/`)에서 방금 분석한 결과 → `next=/result/{request_id}` (분석 직후엔 항상 비로그인 상태로 기록된 요청이라 이 공개 조회 경로로 정확히 재구성됩니다)
  - `/history/{id}` 상세 페이지에서 → `next=/history/{id}` (원래 로그인 필요한 페이지라 실제로 이 분기 탈 일은 거의 없음)
  - `/result/{id}` 공개 링크에서 → `next=/result/{id}` (같은 페이지로 복귀)
- 상세 분석 영역은 "AI 생성 분석 / 촬영 정보 및 제작 이력(EXIF·C2PA) / 유사 이미지 검색" 3개의 접이식 아코디언으로 재구성 — 목업의 아코디언 UX를 반영했습니다. **"유사 이미지 검색"은 이번에 새로 추가한 섹션**입니다(기존엔 duplicate_check 데이터가 "핵심 결과" 한 줄에만 녹아있었고 별도 목록으로 안 보여줬음).

### 목업 대비 스코프를 줄인 부분 (솔직히 말씀드림)

- EXIF와 C2PA를 목업처럼 별도 아코디언 2개로 안 쪼개고 **하나로 합쳤습니다** — 둘 다 `metadata_analysis`라는 같은 데이터 객체 안에 있어서, UI만 쪼개는 건 코드 복잡도만 늘고 실질적 이득이 적다고 판단했습니다. 필요하시면 분리하겠습니다.
- 색상/간격 등 목업의 디테일을 픽셀 단위로 그대로 베끼진 않았고, 기존 다크테마 디자인 시스템 톤에 맞춰 구현했습니다.

## Supabase Auth 리다이렉트 관련 참고

지금 상세 분석 버튼이 그 자리에서 바로 구글 로그인을 트리거하므로(별도 페이지 이동 없이), **Redirect URLs 목록에 `/auth/callback`이 등록돼 있어야 하는 건 기존과 동일**하지만, 이번엔 리다이렉트 시작점이 `/`, `/history/[id]`, `/result/[id]` 등 여러 페이지가 될 수 있습니다 — 다만 Supabase가 실제로 체크하는 건 **`redirectTo`로 넘어가는 콜백 URL 자체**(`/auth/callback`)이지 시작 페이지가 아니라서, 기존에 등록해두신 Redirect URLs 설정 그대로 문제없이 동작합니다.

## API 명세서

`docs/API_SPEC_EXTENSION.md`에 별도로 정리했습니다 (공유용으로 만들었습니다). 핵심 요지:
- 익스텐션이 실제로 쓰는 건 `POST /api/analyze/image-url` 하나뿐
- 인증 없음, IP당 10분 20회 rate limit, CORS는 `chrome-extension://` origin만 허용
- 익스텐션엔 어떤 비밀값도 넣으면 안 되고, Supabase에 직접 연결하는 것도 금지 — 전부 웹서비스 API를 거쳐야 함
