## 한 줄 요약

3-LLM(OpenAI/Gemini/Claude) 비전 앙상블 + DINOv3 선형 프로브를 4번째 시그널로 묶어, 메타데이터(EXIF/PNG/C2PA) 분석과 함께 AI 생성 이미지 여부를 판별하는 Next.js 서비스. Supabase(Postgres+pgvector)에 이미지/로그를 저장하고, phash·임베딩 기반 중복/유사 이미지 탐지로 LLM 비용을 절감합니다. 로컬 테스트용 Chrome 확장(사이드패널)도 있습니다.

**⚠️ 가장 중요한 상태**: 지난 커밋(`70064ad`) 이후 이번 문서 작성 시점까지의 모든 작업이 **아직 커밋되지 않았습니다**. 커밋 방법은 채팅 답변 참고.

## 지금까지 뭘 했나 (라운드별 요약)

1. **코드 리뷰 + Critical 버그 수정** — LLM `is_mock` 처리, aggregator 방향(부호) 버그, `toPercentageScore(1)` 반전 버그, EXIF 회전 리사이즈 버그, PNG iTXt 압축 해제 버그, 요청 바디 무제한 버퍼링(DoS) 등.
2. **pgvector 완전 연동** — `ml/serve.py`가 DINOv3 임베딩을 반환하도록 하고, Supabase에 저장·kNN 검색까지 실제 연결. phash(1단계) → 임베딩(2단계 폴백) 유사 이미지 검색.
3. **보안 강화** — 이미지 포맷 화이트리스트(sharp 디코딩 기반), IP 기반 rate limiting(스푸핑 취약점 발견 후 수정), SSRF 방어(기존에 있던 것 확인).
4. **디자인 리스킨** — 디자이너가 준 Figma 번들을 디코딩해서 모노크롬 디자인 시스템(현재 웹앱 전체에 적용됨) + Chrome 확장 사이드패널.
5. **중복/유사 이미지 탐지 고도화** — 완전 동일 이미지는 LLM 호출 자체를 스킵(비용 절감), 유사 이미지는 점수에 반영 + "어떤 이미지와 유사한지" 표시.
6. **메타데이터 확장** — 카메라 촬영정보(기종/촬영일시/노출/위치정보 유무), 파일 정보(형식/해상도/용량/색공간) 전체 표시.
7. **토큰/비용/지연시간 추적** — provider별 실제 API 사용량, USD 환산 비용(추정치), 지연시간을 캡처해서 로그 + UI에 표시.
8. **PDF/Markdown export 기능 제거** — 회의 결정에 따라 완전히 삭제.

## 디렉터리별 파일 설명

### `app/` — Next.js App Router

| 파일 | 역할 |
|---|---|
| `app/page.tsx` | 메인(유일한) 페이지. 업로드/URL 입력 → 분석 요청 → 결과 렌더링까지 전부 여기. |
| `app/layout.tsx` | 루트 레이아웃. Pretendard/Inter 폰트 로드. |
| `app/globals.css` | 전역 색상/폰트 토큰(Tailwind v4 `@theme`). |
| `app/api/analyze/image/route.ts` | 파일 업로드 분석 API. 확장자 사전검사 → rate limit → `analyzeImageBytes()` 호출. |
| `app/api/analyze/image-url/route.ts` | URL 입력 분석 API. SSRF 방어(`safeFetch`) → 동일 파이프라인. 익스텐션이 호출하는 CORS 대응 라우트이기도 함. |
| `app/api/health/route.ts` | 헬스체크 — 어떤 LLM API 키가 설정돼 있는지만 반환. |

### `lib/analysis/` — 분석 파이프라인 핵심

| 파일 | 역할 |
|---|---|
| `pipeline.ts` | **전체 흐름의 지휘자**. 검증 → phash 조회(동일 이미지면 LLM 스킵) → 메타데이터 분석 → LLM 3개+DINO 병렬 호출 → 2단계 유사도 검색 → 집계 → 저장. |
| `aggregator.ts` | 메타데이터 점수 + 비전 모델 점수 + 시각 근거 + 유사 이미지 이력을 하나의 최종 점수(0-100)로 합산. |
| `metadata.ts` | EXIF(exifr) + PNG tEXt/iTXt 청크 파싱. AI 도구 흔적, 카메라 정보 추출. |
| `phash.ts` | Perceptual hash(DCT 기반) 직접 구현. |
| `router.ts` | quick/standard/deep 모드에 따라 어떤 LLM을 부를지, 메타데이터만으로 충분한지 결정. |
| `dino.ts` | DINOv3 추론 서버(`ml/serve.py`) 호출, 임베딩+판정 반환. |

### `lib/vision/` — 3-LLM 클라이언트

| 파일 | 역할 |
|---|---|
| `openai.ts` / `gemini.ts` / `anthropic.ts` | 각 provider API 호출. 프롬프트 전송 → 응답 파싱 → 토큰/지연시간 캡처. |
| `prompts.ts` | 3개 provider가 공유하는 프롬프트 템플릿 + 이미지 타입(사진/일러스트/픽셀아트) 감지. |
| `normalize.ts` | **일관성의 핵심** — provider마다 다른 응답을 하나의 `VisionResult` 스키마로 강제 변환. |
| `errorMessage.ts` | 에러를 `missing_api_key`/`rate_limit`/`timeout`/`content_policy` 등으로 분류. |
| `pricing.ts` | 모델별 100만 토큰당 단가(수기 입력, 주기적 확인 필요) → USD 비용 추정. |

### `lib/db/`, `lib/storage/`, `lib/logging/`, `lib/supabase/` — 데이터 계층

| 파일 | 역할 |
|---|---|
| `db/imageRecords.ts` | phash/임베딩 유사도 검색 RPC 호출, 분석 결과 저장. |
| `storage/imageStore.ts` | 분석한 이미지를 Supabase Storage에 저장(Supabase 전용, 로컬 저장 없음). |
| `logging/analysisLogger.ts` | 모든 요청을 `request_logs` 테이블에 기록. IP 추출 로직 포함(rate limit과 공유). |
| `supabase/client.ts` | service_role 키로 Supabase 클라이언트 생성(서버 전용). |

### `lib/net/`, `lib/security/`, `lib/image/`, `lib/utils/` — 인프라

| 파일 | 역할 |
|---|---|
| `net/safeFetch.ts` | URL 입력 분석의 SSRF 방어(사설 IP 차단, redirect 재검증, 크기 제한). |
| `net/cors.ts` | Chrome 확장(다른 origin)이 API를 호출할 수 있게 하는 CORS 헤더. |
| `security/rateLimit.ts` | IP당 요청 수 제한(인메모리, 단일 프로세스 한정). |
| `image/preprocess.ts` | EXIF 회전 보정 + 리사이즈 + JPEG 변환. |
| `utils/score.ts` | 점수 변환 유틸(`toPercentageScore`=provider 0~1용, `clampPercent`=이미 0~100인 값용 — 헷갈리면 버그 남). |
| `utils/bbox.ts` | bounding box 유효성 검사. |

### `components/` — UI

`layout/AppHeader.tsx`(헤더), `upload/`(업로드 UI), `results/`(점수 게이지·provider 카드·메타데이터 카드·의심영역 캔버스 등 결과 화면 전체) — 전부 이번 세션에 모노크롬 디자인으로 리스킨됨.

### `types/analysis.ts`

전체 API 계약의 단일 진실 공급원. `AnalysisResult`가 최종 응답 형태, `VisionResult`가 provider별 결과, `MetadataAnalysis`가 메타데이터. 이 파일 하나만 봐도 API가 뭘 주고받는지 다 파악됩니다.

### `ml/` — DINOv3 학습/서빙 (별도 Python 런타임)

`serve.py`(상시 추론 서버), `backbone.py`(모델 로딩), `extract_embeddings.py`/`train_linear_probe.py`(학습), `infer.py`(단발 추론), `build_dataset_from_*.py`(데이터셋 수집), `DINOV3_SETUP.md`(DINOv2→v3 전환 가이드).

### `extensions/chrome/` — 로컬 전용 Chrome 확장

`manifest.json`(MV3 설정), `background.js`(우클릭 메뉴), `sidepanel.js`/`.html`/`.css`(결과 패널 — React 없이 순수 JS로 웹앱 로직 일부를 복제).

### `supabase/schema.sql`

DB 스키마 단일 진실 공급원이지만 **자동 반영 안 됨** — 바뀔 때마다 Supabase 대시보드 SQL Editor에 수동 실행 필요.

### `scripts/`

`generate-test-dataset.js`(합성 테스트 이미지 10종 생성), `run-perf-test.js`(그 이미지들로 성능 테스트), `inspect-png-chunks.js`(PNG 메타데이터 디버그 도구).

### 문서(`docs/`, 루트 `.md`)

`docs/26-07-25 코드리뷰결과보고서.md`(최초 전체 리뷰), `docs/26-07-25 DevDocs.md`(라운드별 상세 변경 이력, 가장 자세함), `docs/HANDOFF_*`/`DINO_AND_STORAGE_INTEGRATION.md`/`DEV_PROGRESS_MODULE_AB.md`(인수인계), `PLAN.md`(최초 설계).
