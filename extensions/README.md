# extensions/

Chrome 확장 프로그램(및 향후 다른 브라우저 확장) 코드를 두는 자리입니다.

**`chrome/`에 로컬 테스트용 MV3 개발 버전이 있습니다** — 로드/테스트 방법은
`chrome/README.md` 참고. 아직 Chrome 웹스토어에는 배포하지 않았습니다.

## 왜 별도 repo가 아니라 이 폴더인가

`docs/26-07-25 코드리뷰결과보고서.md`의 "열린 질문에 대한 의견" 참고 — 지금 단계(초기,
팀 1개, `types/analysis.ts` API 계약이 계속 바뀌는 중)에서는 확장 프로그램이 결국 이
웹서비스의 API를 호출하는 얇은 클라이언트라 강하게 결합돼 있고, 별도 repo로 쪼개면
API가 바뀔 때마다 두 저장소를 오가며 버전을 맞춰야 하는 오버헤드가 지금 단계에서는
이득보다 큽니다.

**분리를 고려할 시점**: API 계약이 안정화되고, 확장 프로그램만의 릴리스 주기(Chrome
웹스토어 심사 대기 등)가 웹서비스 배포를 막기 시작하거나, 별도 팀/일정으로 운영하게
될 때. 그전까지는 모노레포 쪽이 되돌리기도 쉽습니다.

## 시작할 때 참고할 것

- 웹서비스 API 계약: `types/analysis.ts` (`AnalysisResult`), 엔드포인트는
  `app/api/analyze/image/route.ts`(파일 업로드), `app/api/analyze/image-url/route.ts`(URL).
- 확장 프로그램 개발 착수 여부/시점은 아직 결정된 바 없습니다 — 이 폴더에 실제 코드를
  추가하기 전에 먼저 논의가 필요합니다.
