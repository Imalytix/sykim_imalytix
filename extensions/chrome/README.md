# Imalytix Chrome 확장 (개발 버전)

MV3 사이드패널 확장. 이미지 위에서 우클릭 → "Imalytix로 이 이미지 분석하기" → 사이드패널이
열리며 `imalytix-panel-standalone.html` 디자인과 동일한 레이아웃으로 결과를 보여줍니다.

**아직 Chrome 웹스토어에 배포하지 않았고, 이 문서도 로컬 전용 테스트만 다룹니다.**

## 로컬에서 테스트하는 법 (배포 없이)

1. 분석 서버를 먼저 띄웁니다 (다른 터미널에서):
   ```bash
   npm run dev          # http://localhost:3000
   ```
2. Chrome 주소창에 `chrome://extensions` 입력
3. 우측 상단 "개발자 모드" 켜기
4. "압축해제된 확장 프로그램을 로드합니다" 클릭 → 이 폴더(`extensions/chrome`) 선택
5. 툴바에 Imalytix 아이콘이 생깁니다. 아무 웹페이지에서나 이미지를 우클릭해보세요.

코드를 수정한 뒤에는 `chrome://extensions`에서 새로고침(⟳) 아이콘만 누르면 반영됩니다 —
재설치할 필요 없습니다.

## 왜 서버 URL이 필요한가

이 확장은 이미지를 직접 분석하지 않습니다 — `image_url`만 Next.js API
(`/api/analyze/image-url`)로 넘기고, 실제 다운로드/검증(SSRF 체크 등)/분석은 항상 서버가
합니다. 기본값은 `http://localhost:3000`이고, 툴바 아이콘 → ⚙ 설정에서 바꿀 수 있습니다.

`manifest.json`의 `host_permissions`가 `localhost`/`127.0.0.1`만 허용하므로, 배포된 서버
주소로 바꾸려면 그 주소를 `host_permissions`에도 추가해야 fetch가 성공합니다 (그렇지
않으면 CORS로 막힙니다 — 서버 쪽에 CORS 헤더를 추가할 필요는 없습니다: 확장 페이지에서의
요청은 `host_permissions`에 등록된 origin에 한해 브라우저가 CORS 검사를 건너뜁니다).

## 파일 업로드는 왜 없나

사이드패널은 URL만 받습니다 — 우클릭 흐름(가장 흔한 사용 패턴: 이미 웹페이지에 있는
이미지 판별)과 정확히 맞고, 구현이 단순합니다. 로컬 파일을 확장에서 직접 올리는 기능은
이번 스코프에 없습니다(필요하면 웹서비스를 쓰면 됩니다) — 원하시면 다음 라운드에 추가할 수
있습니다.

## 알려진 제약

- 아이콘은 브랜드 로고 크롭이 아니라 헤더의 로고 마크(다크 사각형 + 흰 점)를 재사용해
  즉석에서 생성한 것입니다. 실제 배포 전에 디자이너 확인 필요.
- `manifest_version: 3`의 `chrome.sidePanel` API는 Chrome 114+ 필요.
- 배포(Chrome 웹스토어 등록, 프로덕션 서버 연결, 아이콘 확정)는 이번에 다루지 않았습니다.
